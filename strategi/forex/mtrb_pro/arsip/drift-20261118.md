## 4. Launcher MT5 ada di `/tmp` — SUDAH DIPERBAIKI 2026-11-18

`/tmp/run_mt5.sh` dan `/tmp/run_mt5_live.sh` (dirujuk `mt5-ex-demo.service` dan
`mt5-ex-live.service` lewat `start-mt5-tmux.sh` / `start-mt5-live.sh`) dulu berada
di `/tmp`.

**Penyebab sebenarnya lebih keras dari dugaan awal.** Bukan "terhapus setelah 30
hari" — `tmpfiles.d` memakai tipe **`D`**:

```
D /tmp 1777 root root 30d
```

Tipe `D` = isi direktori **dikosongkan setiap boot** (dijalankan
`systemd-tmpfiles --create --remove --boot` saat `systemd-tmpfiles-setup`).
Jadi launcher itu patah di **setiap** reboot, bukan setelah sebulan.

Bukti saat reboot 2026-11-18 22:11: setelah boot, `mt5-ex-demo` dan `mt5-ex-live`
melaporkan `Finished` (exit 0) padahal `terminal64` tidak ada sama sekali, dan
`tmux ls` menjawab `no server running` — karena skrip yang dijalankan tmux
sudah tidak ada. Feed `mt5_live`/`mt5_demo` jadi `error`.

Perbaikan yang dikerjakan:

| Langkah | Hasil |
| --- | --- |
| Launcher dipindah ke `/home/admin/opt/mt5/run/{run_mt5.sh,run_mt5_live.sh}` | permanen, tidak kena tmpfiles |
| `start-mt5-tmux.sh` + `start-mt5-live.sh` diarahkan ke path baru | `sed` terverifikasi |
| `/usr/local/sbin/mt5-beat.sh` diarahkan ke path baru | terverifikasi |
| Stack MT5 di-restart berurutan | `xvfb` → `openbox` → `x11vnc` → `ex-demo` → `ex-live` |
| Verifikasi | 2 `terminal64` jalan, sesi tmux `mt5` + `mt5live` hidup, feed `mt5_live`/`mt5_demo` `ok` (~19 s) |

**Aturan ke depan:** jangan pernah menaruh skrip yang dirujuk unit systemd di
`/tmp`. `/tmp` dikosongkan tiap boot di server ini.
