# Changelog Sektor 09 — QA & Pengujian

Catatan perubahan pada suite pengujian otomatis, cakupan skenario E2E, dan verifikasi alur pengguna.

## Perkembangan Terkini

### Ditambahkan
- **Suite E2E Playwright Komprehensif (`apps/web/tests`)**: 47 berkas skenario pengujian browser otomatis yang mencakup seluruh antarmuka operasional (dashboard, halaman area, formulir otorisasi, inspeksi ledger, dan visualisasi grafik).
- **Verifikasi Kontrak 5 Blok Wajib**: Pengujian E2E khusus untuk memastikan setiap area pasar merender blok KPI, Radar, Ledger, Autonomy, dan Kebijakan sesuai spesifikasi blueprint.
- **Skrip Verifikasi CI Lokal (`ops/ci-local.sh`)**: Alat verifikasi sekali jalan yang mereplikasi alur GitHub Actions (linting ruff, pemeriksaan tipe svelte, suite pytest backend, vitest frontend, dan audit secret gitleaks).
- **Pengujian Fallback SSE**: Pengujian perilaku antarmuka saat koneksi stream Server-Sent Events terputus dan kembali pulih secara transparan.

### Diperbaiki
- Sinkronisasi waktu tunggu (timeout) pada pengujian E2E yang berinteraksi dengan stream real-time untuk mencegah kegagalan flaky di mesin CI.
- Isolasi lingkungan uji dengan database SQLite in-memory dan mock transport notifikasi null sehingga suite dapat dijalankan tanpa dependensi eksternal.
