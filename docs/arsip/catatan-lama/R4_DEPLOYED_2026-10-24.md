## Kontrak baru (sinyal OK)
```json
{
  "status": "OK",
  "side": "SHORT",
  "levels_mode": "relative",
  "risk": 2.61,
  "reward": 4.70,
  "generated_at": 1792827703,
  "levels": { "entry": 4007.9, "sl": 4010.51, "tp1": 4003.2 }

```
`levels` tetap dikirim untuk pembacaan manusia, tetapi EA **mengabaikannya**
selama `levels_mode == "relative"`.

## Perubahan EA
```cpp
if(modeRelatif) {
   if(jarakRisk <= 0 || jarakReward <= 0) tolak;
   if(side == "LONG") { entry = ask; sl = entry - jarakRisk; tp1 = entry + jarakReward; }
   else               { entry = bid; sl = entry + jarakRisk; tp1 = entry - jarakReward; }
   NormalizeDouble(..., _Digits);
}
```
- kunci anti-duplikat memakai `generated_at + side` pada mode relatif, karena
  entry/sl berubah tiap poll mengikuti harga broker
- `InpFailCooldownSec = 120`: setelah order ditolak broker, EA diam 2 menit
  (mencegah spam percobaan saat pasar tutup)

## Keputusan yang menunggu owner
Ambang `laya_min_confidence = 0.60` sementara Laya konsisten memberi **0.546**.
Selama selisih ini bertahan, EA **tidak akan pernah** menerima sinyal — aman,
tetapi berarti tidak trading sama sekali.

Pilihan:
1. Turunkan ambang ke 0.50 (menerima verdict "ragu")
2. Biarkan 0.60 dan terima bahwa Laya sering memblokir
3. Kumpulkan dulu statistik verdict setelah pasar buka (Senin), baru putuskan

Rekomendasi: **opsi 3** — jangan turunkan ambang berdasarkan data pasar tutup.
