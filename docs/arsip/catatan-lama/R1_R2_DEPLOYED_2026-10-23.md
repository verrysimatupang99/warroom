Parameter baru:
```
InpMinRR          = 0.80   // tolak bila reward/risk < 0.80 pada harga fill
InpMaxDriftFrac   = 0.30   // tolak bila harga sudah bergerak >30% jarak menuju TP
InpMaxSignalAgeSec = 60    // tolak sinyal lebih tua dari 60 detik

```

Fungsi baru `ValidasiRRFill(side, fill, sl, tp, &risk, &reward, &alasan)`:
- menghitung ulang `risk` dan `reward` dari **harga fill** (ask untuk LONG, bid untuk SHORT)
- menolak bila `reward/risk < InpMinRR`
- menolak bila `risk / (risk+reward) > InpMaxDriftFrac` (harga sudah terlalu dekat TP)

Dipanggil di blok LONG dan SHORT, **sebelum** `trade.Buy()` / `trade.Sell()`.
