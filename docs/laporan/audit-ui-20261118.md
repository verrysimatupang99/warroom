## Detail

### Perbaikan #1–#3 (bukti)
- Sebelum: `curl /api/v1/tencent/mt5/status` → `{"error":{"code":"internal"}}`; UI forex = DISCONNECTED, equity $0.
- Log API: `PermissionError: [Errno 13] ... /etc/warroom/service_token.env`.
- `namei -l` → `/etc/warroom` = `drwxr-x--- root:sudo`; `admin` (uid 1001, bukan anggota sudo) tak bisa masuk.
- Fix: `setfacl -m u:admin:x /etc/warroom`.
- Sesudah: endpoint kembali `forbidden` (bukan 500) → UI menampilkan `EKUITAS BERJALAN 1075.84 USC ($10.76) · +6.73%`, cocok dengan `v1.account_snapshot` dan `recon_check` (drift 0).

### Temuan #4 (belum diperbaiki)
`GET /api/v1/infra/health` membaca snapshot `/home/admin/warroom/var/infra-health.json`
yang **di-push dari cyber1** dan berisi status instabox:
```json
{"host":"cyber1","mt5":{"box-2aacb3":"down","mt5-paper-1":"down","mt5-paper-2":"down"},
 "instabox_watchdog":{"timer":"active"}}
```
Snapshot segar (umur ~4 mnt), jadi ini **bukan bug cache** — desainnya memang memantau
instabox, yang kini bukan lagi host EA live (EA live jalan di webdock `mt5-ex-live`).

Opsi perbaikan (butuh keputusan pemilik):
- (a) Ubah `InfraBanner` agar membaca status MT5 webdock (`mt5-ex-live`/`mt5-ex-demo`) + feed freshness v1, bukan instabox;
- (b) Tambah webdock ke snapshot infra;
- (c) Sembunyikan banner instabox.
